# Source Coverage Matrix

Purpose: memastikan `recon_v10_with_dorking.drawio` dan OWASP A01-A10 dipakai sebagai coverage map yang source-grounded, tanpa mematikan creative reasoning GPT.

Rules:
- `source_refs` wajib ada untuk hypothesis, manual test-card, report QA, dan retest note.
- `evidence_refs` wajib ada sebelum status naik ke `tested_secure`, `finding_candidate`, atau `confirmed`.
- Checklist tidak boleh menjadi batas kreativitas; anomaly wajib masuk `creative/off-checklist leads`.
- Tanpa browser/Caido/Burp atau artefak tester-owned yang redacted, status maksimal adalah `queued`, `needs_manual`, atau `blocked_*`.

## Status Promotion Gate

| From | To | Required proof |
|---|---|---|
| `untested` | `queued` | Source ref plus scoped hypothesis |
| `queued` | `needs_manual` | Missing account/scope/evidence/action from hunter |
| `queued` | `tested_secure` | Manual browser/Caido/Burp test with redacted evidence ref and expected-vs-actual match |
| `queued` | `finding_candidate` | Manual evidence shows expected secure behavior failed and impact path is plausible |
| `finding_candidate` | `confirmed` | Reproducible evidence, impact, scope proof, and report QA are complete |
| any | `blocked_by_scope` | Program scope/rules do not allow the test |
| any | `creative_lead` | High-signal anomaly requires off-checklist reasoning and a new manual test-card |
